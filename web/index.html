How PatchCourt works

A case file that can move value.

Judgment stays nondeterministic. Funds, permissions and state transitions remain explicit and auditable.

  1. Lock the reward in Arkhai

    The client creates a natural-language escrow with one PCT and names the PatchCourt relay oracle.

  2. Bind evidence to one commit

    Every accepted GitHub item must resolve through the submitted full SHA. Mutable refs, mismatches and HTTP errors fail closed.

  3. Ask validators to judge meaning

    GenLayer validators evaluate each acceptance criterion, compare structured reasoning and finalize one auditable verdict.

  4. Relay only the final decision

    An approved result is recorded against the exact demand context. The freelancer can then collect the escrowed PCT.
