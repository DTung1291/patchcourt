## Narration

> PatchCourt turns natural-language software milestones into enforceable agent agreements. Arkhai locks the reward. The worker submits public evidence pinned to one immutable Git commit. GenLayer validators fetch that exact commit, judge every acceptance criterion independently, and fail closed on missing or mismatched evidence. After a leader rotation, consensus finalized Case One: approved, four of four criteria. PatchCourt relayed the verdict to Arkhai, and the one PCT escrow settled on Sepolia. Reproducible code, public evidence, and machine-speed Internet Court.
